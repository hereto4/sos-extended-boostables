Changelog v1.4.0

- added CLASS_<CLASSNAME> keys for Nobles, Slaves, and Plebeians; in-game "ClassName (Contentment)"

-- needier = higher basic needs (thirst, hunger, shopping)

-- allows assigning roomtype effects on a per-cass basis

- fixed CaC's tech effect color-coding + sorting logic and moved it to this mod
- added RATES_NATURE key, that lets subjects worship at nature objects for piety gain (see mod description for details)
- added TARGET_CLASS key, allowing effect-scoping to subject class (Noble, Plebeian, Slave, Ex-Slave)
CHANGES
- Moved TARGET_RACE from Create-A-Culture to instead live in this mod (allows effect-scoping to subject race)
