** ==========================================================================
**  Extended Boostables - Update Notice
**  -------------------------------------------------------------------------
**  This single file controls the "mod updated" popup that appears the FIRST
**  time a player enters a game after this mod's _Info VERSION changes.
**
**  It only fires when BOTH are true:
**    1. The mod's _Info VERSION differs from the last version already shown
**       (tracked per-install in
**        %APPDATA%/songsofsyx/saves/profile/sos-extended-boostables-update.txt).
**    2. ENABLED below is true.
**
**  Each release: edit CHANGES (and TITLE), and set ENABLED as desired.
**  Set ENABLED: false to suppress the popup for this release. A disabled
**  release is NOT recorded as "shown", so flipping it back to true on a later
**  load will still show these notes for the same version.
**
**  There is also a hard master switch in code: UpdateNotifier.ENABLED
**  (your.mod.update.UpdateNotifier) - set it false to disable the feature
**  entirely regardless of this file.
**
**  CHANGES markup (one entry per line):
**    "# Heading"      large heading      "## Heading"  smaller heading
**    "---"            horizontal divider  ""            blank spacer
**    "[tag] text"     colored text; tags: good great bad worst warn error
**                     label sub normal   (unknown tag = left as literal)
**
**  NOTE: lines beginning with ** are comments (the game's Json format).
** ==========================================================================
